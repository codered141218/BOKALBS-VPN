    Playing Warcraft III & LAN games

    Quick start
    1. Everyone connects to the same network here first.
    2. Then start the game and open Local Area Network (LAN).
    3. One player creates the game – the others will see it in their LAN list.
    Game not showing up?
    • Restart the game after connecting the VPN.
    • Allow the game in Windows Firewall when asked (tick both Private and Public).
    • Disconnect other VPN programs (Hamachi, Radmin, ZeroTier) while playing.
    • Check the player list: if someone shows via server it still works, just with a little more delay.
    • Warcraft III 1.29+ also has a "Direct IP" option – type the host's VPN address.
    Windows file sharing (\\address)

    Folders you share in Windows (right-click → Properties → Sharing) are reachable at \\your VPN address. Friends log in with a Windows account of your PC. Use "Map network drive" to make it look like a local drive.
